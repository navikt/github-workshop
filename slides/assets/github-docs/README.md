The image files are **unmodified**. Slides only resize them for display, without cropping, recoloring, or changing their labels. Surrounding captions, alt text, and facilitator notes are workshop additions. Retain the image attribution and license links when redistributing the slides or exporting them to PDF.

Screenshots are documentation examples, not captures of participants or the cafe exercise. They may show different repository names, branch names, counts, visibility, or an older interface. In particular, the fork screenshots show `compare: main`; the workshop uses `compare: add-menu-item`. Do not copy example values without checking the actual source and destination.

The merge diagram illustrates the merge-commit method, not every possible merge strategy. Its A-C commits are shared history, D-E are draft changes, and F joins them into main. Other merge methods are outside the workshop's scope.
