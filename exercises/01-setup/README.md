## Part 1: Create Your GitHub Account (10 minutes)

### Why GitHub?

Before we start, let's understand what GitHub is:
- **Version Control Platform:** Like "Track Changes" for any file type
- **Collaboration Hub:** Work with teams from anywhere
- **Portfolio:** Showcase your projects and contributions
- **Free:** No cost for public repositories and small teams

### Create Your Account

1. **Visit [github.com](https://github.com)**

2. **Click the "Sign up" button** (top-right corner or prominent on the page)

3. **Enter your email address**
   - Use an email you check regularly
   - You'll need this for notifications and password recovery
   - Click "Continue"

4. **Create a password**
   - Must be at least 15 characters OR
   - At least 8 characters with a number and lowercase letter
   - Tip: Use a password manager!
   - Click "Continue"

5. **Choose your username**
   
   This is important! Your username will be:
   - Part of your profile URL: `github.com/yourusername`
   - Visible on all your contributions
   - How people @mention you
   
   **Username Tips:**
   - ✅ Professional (you might use this for job applications!)
   - ✅ Memorable and easy to type
   - ✅ Similar to your other professional handles
   - ❌ Avoid numbers unless meaningful
   - ❌ Avoid special characters (use hyphens if needed)
   
   **Good Examples:**
   - `sarah-johnson`
   - `alex-codes`
   - `maria-designs`
   
   **Less Ideal:**
   - `xXcoolkid123Xx`
   - `randomuser45872`
   - `qwerty`
   
   Click "Continue"

6. **Email preferences**
   - Choose whether you want product updates and announcements
   - You can change this later in settings
   - Click "Continue"

7. **Verify you're human**
   - Complete the CAPTCHA puzzle
   - This might involve clicking images or solving a challenge

8. **Click "Create account"**

🎉 **You've created your GitHub account!**

## Part 2: Verify Your Email (2 minutes)

**This step is crucial!** Some GitHub features require a verified email.

### Steps:

1. **Check your email inbox**
   - Look for an email from GitHub (no-reply@github.com)
   - Subject: "Verify your email address"

2. **Can't find it?**
   - Check your spam/junk folder
   - Wait a minute and refresh
   - Still nothing? Click "Resend verification email" on GitHub

3. **Click the verification link** in the email
   - This opens GitHub and confirms your email
   - You'll see a success message

4. **All set!** You now have a verified GitHub account

## Part 3: Explore the GitHub Interface (3 minutes)

Let's take a quick tour of GitHub's main areas.

### Navigation Bar (Top)

Look at the top navigation bar:
- **Search Bar** - Find repositories and users
- **Pull requests** - Your pull request activity
- **Issues** - Your issues and mentions
- **Marketplace** - Apps and tools
- **Explore** - Discover interesting projects
- **Profile Icon** (top-right) - Access your profile and settings

### Your Profile

1. **Click your profile icon** (top-right)
2. **Select "Your profile"**

You'll see:
- Your username and bio (empty for now)
- Contribution graph (will fill up as you use GitHub)
- Repositories (none yet)
- Stars (repos you've favorited)

## Part 4: Settings & Preferences (Optional)

Let's explore your account settings:

1. **Click your profile icon** → **Settings**

### Important Settings to Know:

#### Public Profile
- Edit your profile information
- Add a profile README (advanced - we'll learn about this later!)

#### Account
- Change username (careful - affects URLs!)
- Delete account (don't do this!)

#### Emails
- Add/remove email addresses
- Choose primary email
- Email privacy settings

#### Notifications
- Configure how you receive notifications
- Email, web, or both
- Customize what types of events notify you

#### Appearance
- **Theme:** Light, Dark, or Auto
- Emoji skin tone preferences

**Tip:** Explore these settings, but default options work great for beginners!

## Security Best Practices

Now that you have an account, protect it:

### Enable Two-Factor Authentication (Highly Recommended!)

1. Go to **Settings** → **Password and authentication**
2. Click **Enable two-factor authentication**
3. Choose method:
   - **Authenticator app** (most secure - use Google Authenticator, Authy, etc.)
   - **SMS** (less secure but better than nothing)
4. Follow the setup wizard
5. **Save your recovery codes** in a safe place!

### Other Security Tips

- ✅ Use a strong, unique password
- ✅ Enable 2FA (see above)
- ✅ Never share your password
- ✅ Be careful with personal access tokens
- ✅ Review security log regularly (Settings → Security log)

## Common Questions

**Q: Is GitHub really free?**  
A: Yes! Free accounts have generous limits that work for most personal use.

**Q: Can I change my username later?**  
A: Yes, but it affects your profile URL and can break links. Choose carefully!

**Q: What if I forget my password?**  
A: Use the "Forgot password" link on the login page. This is why email verification is important!

**Q: Do I need to download anything?**  
A: Not for this workshop! We'll use GitHub's web interface. Desktop apps are optional.

**Q: Can people see my email address?**  
A: Only if you choose to make it public. By default, GitHub uses a private email for commits.

**Q: Is GitHub safe?**  
A: Yes, GitHub takes security seriously. Use 2FA for extra protection.

## Troubleshooting

### Email Not Arriving
- Check spam/junk folder
- Wait a few minutes
- Try resending from GitHub
- Try a different email address

### Username Already Taken
- Try variations with hyphens
- Add your specialty (e.g., `john-codes`, `sarah-designs`)
- Check if the existing user is inactive (you might be able to claim it)

### Can't Complete CAPTCHA
- Refresh the page and try again
- Use a different browser
- Disable VPN temporarily
- Contact GitHub Support if persistent
