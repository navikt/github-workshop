# Exercise 01 - Account Setup

**Time:** 5-minute demo and individual attempt. Create and verify your account beforehand if possible; verification delays may need the later catch-up buffer.

**Task:** Sign in to GitHub and find where to create a repository.

You only need a browser. Keep passwords, verification messages, and recovery codes private, including when screen sharing.

## Steps

1. If you have an account, sign in at [github.com](https://github.com/).
2. Otherwise, choose **Sign up** and follow GitHub's current prompts. Use an email you can access, a unique password, and a username you're comfortable sharing. Your username does not need to include your real name.
3. Complete the verification steps and verify your email when prompted.
4. Find your profile menu and **Your repositories**.
5. Find **New** or **+ → New repository**. Stop here; we'll create the repository together in Exercise 02.

GitHub's interface changes over time. If a button has moved, ask for help rather than guessing through account settings.

## Done when

- [ ] You can sign in.
- [ ] Your email is verified.
- [ ] You can find the repository creation screen.

Already finished? Find **Your repositories** and wait for the next task. You do not need to memorize a glossary, install Git, or use a desktop app.

**Demo checkpoint:** The facilitator shows the signup entry point and repository navigation, without exposing passwords or verification messages. You then locate those controls on your own screen.

## If you're stuck

For a missing verification email, check spam and GitHub's resend option. Ask the facilitator for navigation help, but never share credentials. If account access remains blocked, you can observe a partner's exercise with their consent, then retry on your own when access is restored.

## Optional account protection

Review **Settings → Password and authentication** for supported two-factor authentication methods. Store recovery codes securely; do not put them in a repository or workshop document.
