# GitHub for Dummies Workshop

Welcome to **GitHub for Dummies** - a comprehensive workshop designed to teach GitHub from the ground up! 🚀

Whether you're a developer, designer, writer, project manager, or anyone who works with files and teams, this workshop will help you master GitHub's powerful collaboration features.

**No prior experience required!** Just bring your laptop and willingness to learn.

---

## 🎯 What You'll Learn

By the end of this workshop, you'll be able to:
- ✅ Create and manage GitHub repositories
- ✅ Track changes with commits and view project history
- ✅ Work safely with branches
- ✅ Review and merge changes with pull requests
- ✅ Collaborate with teammates using issues and discussions
- ✅ Apply GitHub to real-world projects beyond just code

---

## 📚 Workshop Structure

### Part 1: Foundation (45 minutes)
- **[Exercise 01: Setup](exercises/01%20-%20setup/)** - Create your GitHub account
- **[Exercise 02: First Commit](exercises/02-%20first%20commit/)** - Create a repository and make your first changes
- **[Exercise 03: Branches](exercises/03-branches/)** - Learn to work safely with branches

### Part 2: Collaboration (45 minutes)
- **[Exercise 04: Pull Requests](exercises/04-pull-requests/)** - The professional way to propose changes
- **[Exercise 05: Collaboration](exercises/05-collaboration/)** - Work with others using issues and forks
- **[Exercise 06: Practical Applications](exercises/06-practical-applications/)** - GitHub beyond code

## 🚀 Getting Started

### For Workshop Participants

1. **Before the workshop:**
   - Bring a laptop with internet connection
   - (Optional) Create a GitHub account at [github.com](https://github.com)
   - Review the [Workshop Outline](WORKSHOP-OUTLINE.md)

2. **During the workshop:**
   - Follow along with the exercises in order
   - Ask questions anytime!
   - Work with a partner when indicated
   - Check the [Cheat Sheet](CHEAT-SHEET.md) for quick reference

3. **After the workshop:**
   - Complete any exercises you didn't finish
   - Explore the [Resources](resources/) folder
   - Start using GitHub for your own projects!

### For Self-Paced Learners

Work through the exercises at your own pace:
1. Start with [Exercise 01](exercises/01%20-%20setup/)
2. Complete each exercise before moving to the next
3. Practice the concepts with your own projects
4. Join the [GitHub Community](https://github.community/) for support

## 💡 Why GitHub?

GitHub isn't just for programmers! Here's why teams of all types use it:

**For Everyone:**
- 📝 Track every change to your files with full history
- 👥 Collaborate with teammates easily
- 🔍 Review work before it goes live
- 🌐 Access your work from anywhere
- 🆓 Free for public and small private projects

**Real-World Uses:**
- Documentation teams tracking policy updates
- Writers collaborating on books and articles
- Designers managing design specs and assets
- Project managers organizing requirements
- Educators sharing course materials
- Anyone who wants to track changes to files!

## 🎓 Workshop Philosophy

This workshop is built on these principles:

1. **Hands-On Learning** - You'll DO, not just watch
2. **No Dumb Questions** - Every question helps everyone learn
3. **Practical Focus** - Real-world skills you'll use immediately
4. **Inclusive Language** - Accessible to both technical and non-technical learners
5. **Safe to Experiment** - You can't break GitHub by trying things!
